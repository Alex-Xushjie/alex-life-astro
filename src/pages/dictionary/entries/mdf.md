# main distribution frame

**Countable noun; abbreviation: MDF.** · Chapter 01 · `physical`

[Chapter](/dictionary/) · [English index](/dictionary/)

## Definition

A primary distribution frame where telecommunications cables are terminated and interconnected.

## Usage and distinctions

The abbreviation can refer to the main distribution frame itself or, informally, to the room housing it. An MDF is not the same thing as a core switch.

## Common combinations

the MDF room; terminate cables at the MDF; connect the IDF to the MDF
