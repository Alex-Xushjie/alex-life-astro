# intermediate distribution frame

**Countable noun; abbreviation: IDF. Say “an IDF.”** · Chapter 01 · `physical`

[Chapter](/dictionary/) · [English index](/dictionary/)

## Definition

A distribution frame that provides an intermediate point for cable termination and interconnection.

## Usage and distinctions

An IDF is an intermediate distribution point. In everyday site language, IDF can also refer to the room housing it; check the intended meaning.

## Common combinations

an IDF room; the third-floor IDF; uplinks from the IDF

## Examples

> The third-floor IDF contains the access switches for the east wing.

> Please check the uplink labels in IDF-03 before the maintenance window.
